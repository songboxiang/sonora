# UI 设计交接规范（交给设计类模型用）

> 适用对象：准备用专门的设计模型 / 设计工具重做 Squeezelite GUI 视觉时，
> 应该给模型**哪些标准**、以及模型**必须输出哪些内容**给开发方（本 APP）。
> 版本基线：v1.5.1，Python 标准库 `tkinter / ttk` 单文件实现。

## 一、为什么需要这份规范

本 APP 不是 Web 应用：它用 `tkinter / ttk` 绘制，`.app` 内置 Python 3.13 +
Tk 9，Linux 开发环境为 Tk 8.6。设计稿若只给 Figma 截图、CSS 变量或
React 组件，无法直接落地。必须把视觉决策翻译成 **Tk 能表达的参数**：
纯色十六进制、整数字号、整数像素间距、具名 `ttk.Style`、PNG 图标。

## 二、给设计模型的输入标准（必须一并给它）

### 1. 技术约束（硬约束，必须原文给模型）

- 渲染引擎：**Python `tkinter` + `ttk`**，非浏览器；不支持 CSS、HTML、
  SVG 直接渲染、RGBA 半透明、阴影 / 模糊、渐变、圆角容器（只能用纯色 +
  细边框模拟）、自定义字体文件（只能用系统字体）。
- 图标：只能是 **PNG**（`tk.PhotoImage`），或 `ttk` 内置图形；矢量需导出 PNG。
- 主题：必须同时给出 **浅色 / 深色**两套完整色板，且「跟随系统」要能
  在运行时整体切换；所有文字在两套底色上都需满足 WCAG AA 对比度。
- 平台：macOS（Tk 9，Aqua 部分控件背景色不可靠，需用 `ttk` 自绘样式）
  + Linux/X11（Tk 8.6）；最小窗口 **1120 × 760**，需给出窄窗口行为。
- 语言：简体中文为主，含英文元数据；字号层级要能容纳中文（中文比英文高）。
- 依赖：**不允许引入任何第三方 UI 库 / 图标库 / 字体**。

### 2. 风格基准（给模型参考，不是照抄）

- **Lyrion Material Skin**（LMS 官方 Web 皮肤）：主色 `#589e81` / `#6cac92`，
  浅底 `#fafafa`，深底 `#081f22` / 弹层 `#0d292d`；Material 顶栏、卡片、
  高对比分段控件、细进度条。
- **Audirvana**：大字层级、大封面、克制留白、深浅两套统一、状态色克制。
- 现有实现可参考：仓库 `README.md` 功能列表与 `squeezelite_gui.py` 中
  `C` 色板、`_apply_theme()`、`ttk.Style` 定义（`Hero.TLabel`、
  `Muted.TLabel` / `Ok.TLabel` / `Warn.TLabel` / `Card.TFrame`、
  `ThemeSeg.TLabel` / `ThemeSegOn.TLabel`、`Tool.TButton` / `Accent.TButton`）。

### 3. 必须覆盖的页面与组件（清单给模型）

页面：① 参数配置（27 项参数，可滚动）② 音频输出设备 ③ 升级与更新
④ 正在播放（左：大封面 / 曲目 / 进度 / 三列播放控制 / 音频链路卡片；
右：歌词 / 专辑详情 / 歌手·专辑简介 三视图切换）⑤ 音乐库（工具栏、
Treeview 列表 + 44px 正方形封面、详情卡、面包屑下钻）⑥ 帮助 ⑦ 专注大屏
（全屏、ESC 退出、鼠标移动浮出退出按钮、静止 3 秒隐藏）。

组件：顶栏 + 主题分段控件、`ttk.Notebook` 标签、卡片容器、按钮
（主 / 次 / 危险）、输入框、下拉、进度条、Treeview 行、标签 / 徽章、
滚动条、状态提示、模态弹窗、分隔线。

### 4. 必须覆盖的状态矩阵（要求模型逐项给）

浅色 / 深色 / 跟随系统 × 播放中 / 暂停 / 停止 / 加载中 / 网络错误 /
401 需密码 / 空曲库 / 无歌词 / 无封面 / 无简介 / 专辑下钻 /
bit-perfect 直通 / 已转码警告 / 待确认 / 专注大屏显示与隐藏退出按钮 /
窄窗口（1120 宽）不溢出。

### 5. 现有截图与代码

给模型：当前各页面截图（浅 / 深各一套）+ 上面提到的样式定义片段 +
一页「已知问题」清单（例如：封面曾大小不一、主题分段曾只有选中项可读、
「下一曲」曾溢出）。**明确说明这是待改进项，不是要照抄。**

## 三、设计模型必须输出的内容（交付物清单）

> 要求模型按下述文件名与结构输出，全部为纯文本 / JSON / PNG，不要只给
> 一段描述文字，也不要只给一张整体效果图。

1. **`design-tokens.json`** —— 设计令牌，浅 / 深各一套：
   - 颜色：背景 / 顶栏 / 卡片 / 卡片边框 / 主文字 / 次文字 / 主色 / 主色上文字 /
     成功 / 警告 / 错误 / 选中态 / 悬停 / 禁用 / 分隔线 / 进度条底与填充，
     每个都要 `#RRGGBB`，并标注该色在浅 / 深底上的对比度数值。
   - 字号层级：`hero / title / subtitle / body / caption / overline`，
     每级给「字号 px、字重、行高、用途」。
   - 间距：`xs / sm / md / lg / xl` 整数像素；圆角（Tk 不支持则写 0）、
     边框宽度、控件最小高度、列表行高、封面尺寸（44 / 272 / 280 / 420）。
   - 动效：仅允许「显示 / 隐藏延迟」与「颜色过渡」，给毫秒数。

2. **`components.md`** —— 每个组件的规格表：
   组件名、对应 `ttk.Style` 名、尺寸 / padding、浅深色下的前景 / 背景 /
   边框、默认 / 悬停 / 按下 / 选中 / 禁用五态色值、交互反馈、中文文案示例。

3. **`screens/`** —— 每个页面一张线框或高保真图（**PNG 或 SVG**，
   SVG 需同时导出 PNG），标注关键尺寸、间距、层级顺序、对齐基准；
   至少覆盖「正在播放（浅 / 深）」「音乐库」「专注大屏」「参数配置」。

4. **`states.md`** —— 状态矩阵：逐项写明文案、颜色令牌名、控件可见性、
   是否需要加载指示、错误可恢复操作。

5. **`icons-assets.md`** —— 图标清单：名称、语义、尺寸（如 16/24/32 px）、
   浅深两套 PNG、导出要求（透明背景、不含文字、无抗锯齿白边）；
   Logo / App 图标规格（ICNS 7 尺寸）。

6. **`mapping.md`** —— **最关键**：把每个令牌 / 组件映射到本 APP 的
   具体落点，例如「`color.card.bg` → `C["surface"]`、`Card.TFrame`」、
   「`type.title` → `Hero.TLabel` + `-font`」、
   「选中态 → `ThemeSegOn.TLabel`」。没有对应物的要标注「需新增」。

7. **`checklist.md`** —— 验收清单：可被逐条打勾的检查项（对比度、
   三态主题可读、窄窗口不溢出、封面统一正方形、ESC 退出专注模式、
   「下一曲」不被裁切、中文不截断等）。

### 明确要求模型**不要**输出

- React / Vue / SwiftUI / Flutter 组件代码、CSS 文件、Tailwind 类名；
- 只存在于 Figma 的自动布局 / 变体描述（需转成固定像素值）；
- 半透明色、阴影、模糊、渐变、圆角容器、自定义字体文件；
- 未标注尺寸的「看起来差不多」的效果图；
- 引用本 APP 不存在的图标库或第三方资源（许可风险）。

## 五、我（开发方）拿到交付物后会做什么

1. 校验 `design-tokens.json`：对比度、色值格式、字号是否落在 Tk 支持的
   整数字号；把令牌灌进 `C` 色板与 `_apply_theme()` 的浅 / 深两套字典。
2. 按 `mapping.md` 新增 / 调整 `ttk.Style`（`Hero.TLabel`、`Card.TFrame`、
   `ThemeSeg*`、按钮、Treeview 行高与选中色），同步 `_np_after_theme()`
   与 `_focus_theme()` 的换肤刷新列表。
3. 按 `screens/` 调整布局：容器尺寸、`grid/pack` 结构、封面尺寸常量
   （44 / 272 / 280 / 420）、工具栏两行、三列控制区不溢出。
4. 按 `states.md` 补齐空态 / 错误 / 加载态文案与颜色。
5. 按 `icons-assets.md` 用 `assets/make_icon.py` 生成 PNG / ICNS，
   保持纯 Python 生成、不引入第三方资源，避免许可风险。
6. 回归：逻辑测试 + X11 真实 GUI 实例化（几何、三态主题、封面正方形、
   专注大屏 ESC/Motion/3 秒隐藏）+ macOS 内置 Tk 9 冒烟；
   然后同步 `.app`、重签名、提交版本。

> 交付物越结构化，落地越不容易走样。若模型只能给效果图，
> 至少要求它补齐 `design-tokens.json` 与 `mapping.md` 两项。
