# 验收清单 / Acceptance Checklist

> 逐条打勾。落地后按此清单回归。

## 令牌与对比度 / Tokens & Contrast

- [ ] `design-tokens.json` 全部颜色为 `#RRGGBB` 格式，无 RGBA/渐变/阴影值
- [ ] 浅/深两套色板齐全，每个文字色标注对比度数值
- [ ] 正文文字对比度 ≥ 4.5:1（WCAG AA），大字/图形 ≥ 3.0:1
- [ ] 主色在浅/深底上满足文字 AA：浅 `#2F6B52` 6.01:1、深 `#7CC7A6` 8.60:1
- [ ] 字号为 Tk 支持的整数字号（40/24/17/14/12/10）
- [ ] 间距为整数像素；圆角 = 0（Tk 不支持）

## 三态主题 / Three Themes

- [ ] 浅色 / 深色 / 跟随系统三态可运行时切换
- [ ] Auto 跟随系统外观，切换时整体重绘无残留旧色
- [ ] 主题分段控件「未选中项」可读（浅 5.93:1 / 深 8.60:1），不再只有选中项可读
- [ ] 换肤后正在播放页、专注页颜色同步（`_np_after_theme()` / `_focus_theme()`）

## 布局与溢出 / Layout & Overflow

- [ ] 窗口最小 1120×760，`minsize()` 生效
- [ ] 1120 窄窗口下所有页面不溢出、无横向滚动异常
- [ ] 三列播放控制等宽，「下一曲 Next」不被裁切
- [ ] 音乐库工具栏两行布局正确
- [ ] Treeview 列在窄窗口下有横向滚动条，文字不截断
- [ ] 中文文案不被截断（行高按 1.2x 预留）

## 封面与图标 / Cover & Icons

- [ ] 所有封面统一正方形：44 / 272 / 280 / 420，无拉伸变形
- [ ] 无封面时显示统一占位封面（正方形）
- [ ] 图标全部为 PNG，浅深两套，透明背景、无文字、无白边
- [ ] 未引用任何第三方图标库

## 状态覆盖 / States

- [ ] 播放中 / 暂停 / 停止 三态图标与进度正确
- [ ] 加载中有不确定态指示
- [ ] 网络错误显示错误文案 + 重试操作
- [ ] 401 弹出密码模态框，可提交/取消
- [ ] 空曲库 / 无歌词 / 无封面 / 无简介 空态文案齐全
- [ ] 专辑下钻面包屑可返回
- [ ] bit-perfect 直通（success）与已转码（warning）徽章颜色正确
- [ ] 待确认态按钮禁用或弹确认框

## 专注大屏 / Focus Mode

- [ ] 全屏显示，ESC 可退出
- [ ] 鼠标移动浮出退出按钮（120ms 显示）
- [ ] 静止 3 秒后退出按钮隐藏
- [ ] 专注页换肤正确

## 映射与落地 / Mapping

- [ ] `mapping.md` 中每个令牌都有 C[] 落点或标注「需新增」
- [ ] 所有「需新增」的 ttk.Style 已在代码中定义
- [ ] `_apply_theme()` 浅深字典已灌入令牌色值
- [ ] `assets/make_icon.py` 纯 Python 生成 PNG/ICNS，无第三方依赖

## 回归与发布 / Regression & Release

- [ ] 逻辑测试通过
- [ ] X11 真实 GUI 实例化通过（几何 / 三态 / 封面正方形 / ESC / Motion / 3s 隐藏）
- [ ] macOS 内置 Tk 9 冒烟测试通过
- [ ] `.app` 已同步、重签名、版本已提交
