# Sonora 颂诺 — 品牌与知识产权说明

## 命名
- **Sonora 颂诺**：原创组合词。英文由 `sono-`（声音，源自拉丁/意大利语词根）+ `-ra` 构成；中文「颂诺」为音译兼意译（颂扬 + 承诺）。
- 命名时已主动规避已知同类产品商标（Roon、Audirvana、音流、流云音乐、Sonos 等），未使用其名称、缩写或易混淆变体。

## Logo / 图标
- **唱片涟漪**：原创 SVG 矢量图（`web/assets/logo.svg`、`logo-mark.svg`），由同心圆纹路（抽象黑胶唱片）+ 中心发光点（涟漪/播放焦点）+ 深绿到薄荷绿渐变构成，无第三方图形、字体、品牌元素。
- App 图标 `web/assets/Sonora.icns` 由上述 SVG 自行生成（多尺寸 PNG → iconutil）。

## 声明与提醒
- 本品牌名称与图形为本项目原创设计，未抄袭任何现有商标或作品。
- **正式商业发布前，建议在目标地区做一次商标检索**（中国 CNIPA、美国 USPTO、欧盟 EUIPO），并考虑注册；本说明不构成法律意见。
- 若检索发现冲突，可低成本替换：名称集中出现在 `main.py`、`backend/api.py`（getMeta）、`web/index.html`、`web/app.js`、`README.md`；logo 为独立 SVG 文件，替换不影响功能代码。
